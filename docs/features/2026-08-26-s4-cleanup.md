# S4 收尾 (篩選頁 / Splash / 清理舊常數)

## What
1. 清理 `ThemeColor.appPrimary` 與 `ThemeColor.backBtn` 硬編碼常數，改用語意化 `Theme.of(context).colorScheme.primary` 及 `colorScheme.onPrimary`。
2. 移除 `SplashPage` 中不必要的 3 秒 `Future.delayed` 假延遲。
3. 確保 `FilterPage` 及其他使用到 `ThemeColor` 的 18 處 AppBar 與 UI 元件順利遷移至 `ColorScheme`，消除色差。

## Why
- **視覺對齊**：目前 `ColorScheme.fromSeed` 會將品牌色 `#D84A20` 映射為 `#8F4B38`，但各頁面的 AppBar 仍寫死 `#D84A20`，導致明顯色差。
- **最佳實踐**：硬編碼常數破壞了 M3 Design System 的動態色彩架構。
- **使用者體驗**：SplashPage 的 3 秒強制等待無實質載入意義，應移除。

## 範圍與邊界
- 修改所有參考到 `ThemeColor.appPrimary` 和 `ThemeColor.backBtn` 的檔案。
- 修改 `SplashPage` 移除 delay。
- `ThemeColor` 類別內如果只剩常數被 `theme_data.dart` 使用，可以保留作為 seed，但要確認是否可以刪除無用常數。
